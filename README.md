# Квартира 73,92 м² — GreenLine Garden-2

Проект ремонта 3-комнатной квартиры: 3D-модель, три концепции отделки, рендеры, альбом рабочих чертежей, ведомость материалов и план работ.

## Что здесь

| Файл | Что это |
|---|---|
| `index.html` | Интерактивный проект: откройте в браузере (нужен интернет для загрузки three.js и шрифтов) |
| `greenline-73.html` | Тот же проект без обёртки — исходник опубликованной страницы |
| `Альбом чертежей — кв 73,92.pdf` | 10 листов А3, М 1:50: обмерный план, демонтаж/монтаж, мебель, полы, потолки и свет, розетки по группам, трассы кабелей, схема щита, сантехника, обмерный лист |
| `renders/` | 13 концепт-рендеров (Blender Cycles) |
| `blender/` | Модели `.glb` по трём концепциям и скрипт `render.py` |

## Как пересобрать рендеры

```bash
blender -b -P blender/render.py -- blender/dala.glb renders dala 96 living,kitchen,kids,bedroom,bath,loggia,overview
```

## Важно

- Размеры сняты с планировки застройщика и сверены по площадям, точность ±5 см. До закупки и разводки нужен обмер на объекте (вкладка «Обмер» в проекте).
- Перенос стены ванной — перепланировка: нужны эскизный проект и согласование с акиматом.
- Сечения кабелей и номиналы автоматов — проектное решение, их подтверждает электрик после получения ТУ на мощность.
